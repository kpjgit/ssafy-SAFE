# Unity 웹 스트리밍 구현 가이드

## 이게 뭔가요?

Unity에서 만든 3D 시뮬레이터 화면을 **웹 브라우저에서 실시간으로 볼 수 있게** 만드는 기술입니다.

**쉽게 말하면**: Unity 프로그램을 실행하면, 그 화면을 Chrome이나 Safari 같은 웹 브라우저에서도 똑같이 볼 수 있습니다.

## 왜 이런 걸 만들었나요?

### 해결하고 싶었던 문제들
- Unity 프로그램을 다른 사람에게 보여주려면 직접 컴퓨터를 가져가야 했음
- Unity가 백그라운드로 가면 화면이 멈춤
- 여러 시점(카메라)를 쉽게 바꿔가며 보고 싶었음

### 이제 가능한 것들
- **어디서든 접속**: 웹 브라우저만 있으면 Unity 화면을 볼 수 있음
- **실시간 확인**: Unity에서 뭔가 바뀌면 웹에서도 즉시 반영됨
- **카메라 전환**: 웹에서 버튼 클릭으로 다른 시점으로 변경 가능

## 어떻게 작동하나요?

### 전체 과정 (간단 버전)
1. **Unity**: 카메라로 화면을 찍어서 사진으로 만듦
2. **압축**: 사진을 웹으로 보내기 좋게 압축함 (JPEG)
3. **전송**: 인터넷으로 웹 브라우저에게 사진을 보냄
4. **표시**: 웹 브라우저에서 사진을 화면에 그림
5. **반복**: 이 과정을 초당 5번 반복해서 동영상처럼 보임

### 기술적 구조 (조금 더 자세히)
```
Unity 프로그램  ──인터넷──►  웹 브라우저
     ↓                        ↓
   카메라로 촬영             사진을 화면에 표시
   사진으로 저장             버튼으로 카메라 전환
   웹으로 전송               실시간으로 업데이트
```

## 핵심 기술 설명

### 1. Unity 쪽 - HTTP 서버

**HTTP 서버가 뭔가요?**
- 웹 브라우저가 "사진 주세요" 하고 요청하면 사진을 주는 프로그램
- 마치 카페에서 "커피 주세요" 하면 커피를 주는 것과 비슷

**우리가 만든 서버의 특징**:
- **포트 8081**: 웹에서 접속할 때 사용하는 문 번호
- **해상도 1280x720**: 웹에서 보기 적당한 크기
- **초당 30장**: Unity에서 1초에 30장의 사진을 찍음

```csharp
// Unity에서 웹 서버 시작하는 코드 (간단 버전)
void StartServer()
{
    // 포트 8081에서 웹 요청을 기다림
    server.Start("http://localhost:8081");
    
    // 누군가 "/frame" 주소로 오면 사진을 줌
    server.AddRoute("/frame", SendCameraImage);
}
```

### 2. 카메라 촬영 시스템

**어떻게 Unity 화면을 사진으로 만드나요?**

1. **카메라 렌더링**: Unity 카메라로 3D 세상을 2D 사진으로 변환
2. **메모리에 저장**: 컴퓨터 메모리에 픽셀 정보를 저장
3. **JPEG 압축**: 파일 크기를 줄이기 위해 압축 (용량 1/10로 감소)
4. **준비 완료**: 웹에서 요청하면 언제든 보낼 수 있게 준비

```csharp
// 카메라로 사진 찍는 코드 (이해하기 쉽게)
void TakeCameraPhoto()
{
    // 1. 카메라로 화면을 찍어서
    camera.Render();
    
    // 2. 픽셀 정보를 읽어서
    ReadPixelsFromCamera();
    
    // 3. JPEG로 압축해서 저장
    photoData = CompressToJPEG();
}
```

### 3. 웹 브라우저 쪽 - 사진 요청 및 표시

**웹에서는 어떻게 Unity 사진을 받나요?**

1. **사진 요청**: "Unity야, 최신 사진 주세요"
2. **사진 받기**: Unity에서 보낸 JPEG 사진을 받음
3. **화면에 그리기**: HTML Canvas에 사진을 그려서 표시
4. **반복**: 200ms마다 (초당 5번) 이 과정을 반복

```typescript
// 웹에서 Unity 사진 받는 코드 (이해하기 쉽게)
async function getUnityImage() {
    // Unity 서버에게 최신 사진 요청
    const response = await fetch("http://localhost:8081/frame");
    
    // 받은 사진을 화면에 표시
    const image = await response.blob();
    displayImageOnScreen(image);
}

// 200ms마다 새 사진 받기 (초당 5번)
setInterval(getUnityImage, 200);
```

### 4. 카메라 전환 기능

**웹에서 Unity 카메라를 어떻게 바꾸나요?**

웹 페이지에 버튼들이 있고, 버튼을 누르면:
1. **요청 전송**: "Unity야, 카메라를 2번으로 바꿔주세요"
2. **Unity에서 처리**: 실제로 카메라를 바꿈
3. **결과 확인**: 다음 사진부터는 새로운 카메라 시점으로 나옴

```typescript
// 웹에서 카메라 바꾸는 코드 (간단 버전)
function changeCamera(cameraNumber) {
    // Unity에게 카메라 변경 요청
    fetch("http://localhost:8081/camera/switch", {
        method: "POST",
        body: JSON.stringify({ cameraIndex: cameraNumber })
    });
}
```

## 성능 최적화

### 프레임 속도 조절

**왜 Unity는 30fps, 웹은 5fps인가요?**

- **Unity 30fps**: 부드러운 움직임을 위해 1초에 30장 촬영
- **웹 5fps**: 인터넷 속도를 고려해 1초에 5장만 요청
- **결과**: Unity는 부드럽게 동작하고, 웹도 적당히 실시간으로 보임

### 메모리 관리

```typescript
// 메모리 정리하는 코드
img.onload = () => {
    // 사진을 화면에 그린 후
    canvas.drawImage(img, 0, 0);
    
    // 메모리 정리 (중요!)
    URL.revokeObjectURL(img.src);
};
```

## 실제 사용법

### 1. Unity 설정하기

1. **스크립트 추가**: UnityHttpVideoServer.cs를 빈 오브젝트에 붙이기
2. **카메라 설정**: 사용할 카메라들을 배열에 드래그해서 넣기
3. **이름 설정**: 각 카메라의 이름을 입력하기
4. **플레이 버튼**: Unity에서 플레이 버튼 누르기

### 2. 웹에서 접속하기

1. **주소 입력**: 브라우저에서 `http://localhost:8081` 접속
2. **자동 재생**: 페이지가 열리면 자동으로 Unity 화면이 나타남
3. **카메라 버튼**: 화면 아래 버튼들로 시점 변경 가능

### 3. 문제 해결

**화면이 안 나와요**
- Unity에서 플레이 버튼을 눌렀는지 확인
- 콘솔창에서 "Server started on port 8081" 메시지 확인
- 방화벽에서 포트 8081이 허용되어 있는지 확인

**카메라가 안 바뀌어요**
- 카메라 배열에 카메라가 제대로 들어가 있는지 확인
- 카메라 이름 배열에 이름이 제대로 입력되어 있는지 확인
